Customer Churn Prediction & Analytics

Project Overview
This project analyzes telecom customer data to identify customer churn patterns and predict customers who are likely to leave a company.

Objectives
 Analyze customer churn behavior.
 Identify important factors influencing churn.
 Build Machine Learning models to predict customer churn.
 Develop an interactive Tableau dashboard.
 Generate insights to support customer retention strategies.
